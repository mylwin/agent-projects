# 保险业务接口文档

本文面向学生说明 `biz-service` 提供了哪些接口、每个接口怎么调用、请求参数是什么、响应字段是什么。



## 基础信息

|本地默认地址|http://127\.0\.0\.1:8001|
|---|---|
|统一接口前缀|/api/v1|
|接口统一格式|Content\-Type: application/json|

业务日期时间按 `Asia/Shanghai`（UTC+08:00）返回，格式示例为 `2026-06-28T10:00:00+08:00`。


## 认证规则

登录或注册成功后，服务会返回 `access_token`：

```JSON
{
  "access_token": "jwt-access-token",
  "token_type": "Bearer",
  "user": {
    "id": 1,
    "username": "demo",
    "email": "demo@example.com",
    "displayName": "demo"
  }
}
```



需要登录的接口必须携带请求头：

```HTTP
Authorization: Bearer <access_token>
```

## 认证接口



### 用户注册

注册新用户。注册成功后返回访问令牌和用户信息。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/auth/register`|否|

**请求体字段**

|字段|类型|必填|说明|
|---|---|---|---|
|`username`|`string`|是|用户名，不能为空|
|`email`|`string`|是|邮箱，必须包含 `@`|
|`password`|`string`|是|密码，长度至少 6 位|

**请求示例**

```bash
curl -X POST http://127.0.0.1:8001/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"student","email":"student@example.com","password":"123456"}'
```

**响应字段**

|字段|类型|说明|
|---|---|---|
|`access_token`|`string`|访问令牌|
|`token_type`|`string`|令牌类型，默认Bearer|
|`user.id`|`number`|用户 ID|
|`user.username`|`string`|用户名|
|`user.email`|`string`|邮箱|
|`user.display_name`|`string`|展示名称|

**响应示例**

```json
{
  "access_token": "jwt-access-token",
  "token_type": "Bearer",
  "user": {
    "id": 2,
    "username": "student",
    "email": "student@example.com",
    "display_name": "student"
  }
}
```

**错误响应**

|HTTP 状态码|错误码|触发条件|
|---|---|---|
|`400`|`INVALID_REGISTER_REQUEST`|用户名为空、邮箱格式错误或密码少于 6 位|
|`409`|`USER_EXISTS`|用户名或邮箱已存在|

```json
{
  "code": "USER_EXISTS",
  "message": "用户名或邮箱已存在"
}
```



### 用户登录

使用用户名或邮箱和密码登录，成功后返回访问令牌和用户信息。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/auth/login`|否|

**请求体字段**：

|字段|类型|必填|说明|
|---|---|---|---|
|`username`|string|是|用户名或邮箱|
|`password`|string|是|密码|

**请求体示例**：

```JSON
{"username":"student","password":"123456"}
```

**响应字段**：同注册接口。

**响应示例**：

```JSON
{
  "access_token": "jwt-access-token",
  "user": {
    "id": 2,
    "username": "student",
    "email": "student@example.com",
    "display_name": "student"
  }
}
```

**错误响应**

|HTTP 状态码|错误码|触发条件|
|---|---|---|
|`400`|`INVALID_CREDENTIALS`|用户名或密码为空，或凭证不正确|

```json
{
  "code": "INVALID_CREDENTIALS",
  "message": "用户名/邮箱或密码错误"
}
```







### 刷新 access token\(选做\)

使用 Refresh Token Cookie 刷新访问令牌并延长登录态。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/auth/refresh`|否|

**请求参数**：无。

**请求示例**：

```TypeScript
const resp = await fetch("http://127.0.0.1:8001/api/v1/auth/refresh", {
  method: "POST",
  credentials: "include"
})
```

**响应字段**：同注册接口。

**响应示例**：

```JSON
{
  "access_token": "new-jwt-access-token",
  "token_type": "Bearer",
  "user": {
    "id": 2,
    "username": "student",
    "email": "student@example.com",
    "displayName": "student"
  }
}
```

**错误响应**

|HTTP 状态码|错误码|触发条件|
|---|---|---|
|`401`|`INVALID_REFRESH_TOKEN`|Refresh Token 缺失、无效或已过期|
|`404`|`USER_NOT_FOUND`|Refresh Token 对应用户不存在|
|`400`|`INACTIVE_USER`|用户已被停用|

```json
{
  "code": "INVALID_REFRESH_TOKEN",
  "message": "Refresh token is invalid or expired"
}
```

### 退出登录\(选做\)

清除 Refresh Token Cookie，结束当前浏览器登录态。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/auth/logout`|否|

**请求参数**：无。

**请求示例**：

```Bash
curl -X POST http://127.0.0.1:8001/api/v1/auth/logout
```

**响应字段**：

|字段|类型|说明|
|---|---|---|
|`ok`|boolean|是否成功退出|

**响应示例**：

```JSON
{
  "ok": true
}
```

### 查询产品保费试算模板

查询指定产品当前生效的保费试算字段和规则模板。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`GET`|`/api/v1/products/{product_id}/pricing-schema`|否|

**Path 参数**：

|参数|类型|必填|说明|
|---|---|---|---|
|`product_id`|number|是|产品 ID|

**请求示例**：

```Bash
curl http://127.0.0.1:8001/api/v1/products/2/pricing-schema
```

**响应字段**：

|字段|类型|说明|
|---|---|---|
|`product_id`|number|产品 ID|
|`scenario`|string|试算场景|
|`schema_version`|string|模板版本|
|`schema`|object|前端动态表单模板|
|`schema.title`|string|表单标题|
|`schema.fields`|array|表单字段列表|
|`schema.fields[].key`|string|字段 key，提交试算时放入 `answers`|
|`schema.fields[].label`|string|前端展示名称|
|`schema.fields[].type`|string|字段类型|
|`schema.fields[].required`|boolean|是否必填|
|`schema.fields[].options`|array|可选项|

**响应示例**：

```JSON
{
  "product_id": 2,
  "scenario": "premium_by_coverage",
  "schema_version": "2026-06-09.v1",
  "schema": {
    "title": "达尔文12号重大疾病保险试算",
    "fields": [
      {
        "key": "insured.age",
        "label": "被保人年龄",
        "type": "number",
        "required": true
      }
    ]
  }
}
```

**错误响应**

|HTTP 状态码|错误码|触发条件|
|---|---|---|
|`404`|`PRICING_SCHEMA_NOT_FOUND`|产品没有生效中的试算模板|

```json
{
  "code": "PRICING_SCHEMA_NOT_FOUND",
  "message": "Pricing schema not found"
}
```



## 保费试算接口



### mock 保费试算

根据产品、方案和被保人信息生成教学用模拟保费试算结果。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/premium/calculate`|否|

**请求体字段**：

|字段|类型|必填|说明|
|---|---|---|---|
|`product_id`|number|是|产品 ID|
|`scenario`|string|否|试算场景，默认 `premium_by_coverage`|
|`answers`|object|是|用户填写的试算项|
|`answers.plan_code`|string|否|计划编码，默认 `basic`|
|`answers.insured.age`|number|按模板|被保人年龄|
|`answers.insured.gender`|string|按模板|被保人性别|
|`answers.insured.social_security`|string|按模板|是否有社保|
|`answers.insured.occupation_class`|string|按模板|职业类别|
|`answers.coverage.coverage_amount`|number|按模板|保额|
|`answers.coverage.deductible`|string/number|按模板|免赔额|

**请求示例**：

```Bash
curl -X POST http://127.0.0.1:8001/api/v1/premium/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "product_id": 2,
    "scenario": "premium_by_coverage",
    "answers": {
      "plan_code": "standard",
      "insured.age": 30,
      "insured.gender": "female",
      "insured.social_security": "yes",
      "coverage.coverage_amount": 300000,
      "coverage.payment_period": "20y",
      "coverage.coverage_period": "lifetime"
    }
  }'
```

**响应字段**：

|字段|类型|说明|
|---|---|---|
|`quote_id`|string|报价 ID，可用于创建订单|
|`product_id`|number|产品 ID|
|`plan_code`|string|计划编码|
|`pricing_mode`|string|计价模式，当前为 `mock_adapter`|
|`annual_premium`|string|年缴保费|
|`payment_frequency`|string|缴费频率|
|`breakdown`|array|保费明细|
|`breakdown[].item`|string|明细项编码|
|`breakdown[].name`|string|明细项名称|
|`breakdown[].premium`|string|明细保费|
|`breakdown[].source`|object|来源说明|
|`warnings`|array|风险提示|
|`expires_at`|string|报价过期时间|

**响应示例**：

```JSON
{
  "quote_id": "4fdaeb2f-3b5e-4fd3-a5b0-4f2f1cfedc5b",
  "product_id": 2,
  "plan_code": "standard",
  "pricing_mode": "mock_adapter",

  "breakdown": [
    {
      "item": "main",

        "adapter": "mock_fosun",

      }
    }
  ],
  "warnings": [
    "本结果由教学 mock adapter 生成，不构成真实保险报价",
```

|`404`|`PRICING_BINDING_NOT_FOUND`|产品没有生效中的试算绑定|
|`400`|`MISSING_PRICING_PARAMS`|缺少模板要求的试算参数|

```json
{
  "code": "INVALID_PRICING_PARAMS",
  "message": "product_id is required"
}
```

### 创建订单

根据报价和推荐结果创建投保订单，并支持幂等提交。

报价可来自当前用户或匿名试算，并须在有效期内。总保费按数据库中的报价相加。使用相同幂等键或确认 ID 重复提交相同内容时，返回原订单。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/orders`|是|

**请求体字段**：

|字段|类型|必填|说明|
|---|---|---|---|
|`quote_ids`|UUID\[\]|否|报价 ID 列表。省略时从 `items[].quote_id` 提取，订单至少需引用一份报价|
|`quoteIds`|string\[\]|否|`quote_ids` 的驼峰写法|
|`idempotency_key`|string|否|幂等键，重复提交时返回原订单|
|`thread_id`|UUID|否|关联当前用户的客服会话 ID|
|`threadId`|string|否|`thread_id` 的驼峰写法|
|`confirmation_id`|string|否|确认 ID|
|`items`|array|否|订单项。不传时根据报价自动生成|
|`items[].quote_id`|UUID|是（提供订单项时）|每项对应的报价 ID，须与 `quote_ids` 一致|
|`items[].product_id`|number|否|产品 ID，提供时须与报价对应的产品一致|
|`recommendation_snapshot`|object|否|推荐方案快照|

**请求示例**：

```Bash
curl -X POST http://127.0.0.1:8001/api/v1/orders \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "quote_ids": ["4fdaeb2f-3b5e-4fd3-a5b0-4f2f1cfedc5b"],
    "idempotency_key": "student-demo-001",
    "items": [
      {
        "quote_id": "4fdaeb2f-3b5e-4fd3-a5b0-4f2f1cfedc5b",
        "product_id": 2
      }
    ],
    "recommendation_snapshot": {
      "plan_name": "演示方案"
    }
  }'
```

**响应字段**：同订单列表中的 items\[\]。

**响应示例**：返回订单列表示例中的单个订单对象，新订单状态为 `pending_payment`。

**错误响应**

|HTTP 状态码|错误码|触发条件|
|---|---|---|
|`401`|`UNAUTHORIZED`|缺少访问令牌，或令牌无效、已过期|
|`400`|`CHAT_THREAD_NOT_FOUND`|关联会话不存在或不属于当前用户|
|`404`|`QUOTE_NOT_FOUND`|请求中引用的报价不存在或不可供当前用户使用|
|`409`|`QUOTE_EXPIRED`|报价已过期|
|`409`|`ORDER_IDEMPOTENCY_CONFLICT`|幂等键或确认 ID 已用于其他订单|
|`422`|`ORDER_ITEM_MISMATCH`|订单项的产品与报价不一致|
|`422`|`REQUEST_VALIDATION_ERROR`|缺少报价、报价重复、订单项与报价列表不一致或参数格式错误|

```json
{
  "code": "QUOTE_NOT_FOUND",
  "message": "报价不存在"
}
```

### 取消订单

取消当前用户的待支付订单。重复取消已取消的订单时，返回当前订单。

|请求方式|请求路径|是否需要登录|
|---|---|---|
|`POST`|`/api/v1/orders/{order_id}/cancel`|是|

**Path 参数**：

|参数|类型|必填|说明|
|---|---|---|---|
|`order_id`|UUID|是|订单 ID|

请求体：无。

**请求示例**：

```Bash
curl -X POST http://127.0.0.1:8001/api/v1/orders/55555555-5555-5555-5555-555555555555/cancel \
  -H "Authorization: Bearer <access_token>"
```

**响应字段**：同订单列表中的 items\[\]。

**响应示例**：返回完整订单对象，状态为 `cancelled`。

**错误响应**

|HTTP 状态码|错误码|触发条件|
|---|---|---|
|`401`|`UNAUTHORIZED`|缺少访问令牌，或令牌无效、已过期|
|`404`|`ORDER_NOT_FOUND`|订单不存在或不属于当前用户|
|`409`|`ORDER_NOT_CANCELLABLE`|当前订单状态不允许取消|
|`422`|`REQUEST_VALIDATION_ERROR`|`order_id` 不是有效的 UUID|

```json
{
  "code": "ORDER_NOT_CANCELLABLE",
  "message": "当前订单状态不允许取消"
}
```
