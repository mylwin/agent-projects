# 前端页面设计与实现边界

## 设计基线

以用户最终附图 `exec-4758c091-2d9e-4887-be0c-f0f7568d369c.png` 为准，采用暖白、酒红与宋体标题的旅行日笺布局。此前方案字母不再作为判断依据。

北极星：像翻开一份留有余地的旅行手册，先读当天安排，再自然地提出修改。

- 桌面端：左侧约七成为旅行手册；手册内为时间轴与照片/小地图两栏；右侧约三成为旅行助手。
- 窄屏：顶部切换「我的行程 / 旅行助手」，保持输入、修改内容和选中日期，照片与路线在活动之后展示。
- 主对象：选中日期的行程。主动作：编辑活动或提出调整要求，自动记录结果，最后选定一个版本为最终方案。
- 样式：纸白 `#fcfaf7`、酒红 `#70405b`、浅玫瑰 `#f0e8e8`；少量边界与阴影，无大面积渐变装饰。
- 字体：系统宋体优先，按 `Noto Serif SC → Songti SC → STSong → serif` 回退；英文标识使用 Georgia。不依赖在线字体。
- 图标：真实 npm 包 `lucide-react`，品牌使用 Compass 细线罗盘，业务使用 MapPin、CalendarDays、Landmark、BookOpen、Utensils 等；统一细描边，不用 Emoji 冒充图标。图标与字标按实际视觉高度配比，桌面为 34px / 26px，窄屏为 30px / 23px。

## 已实现交互

1. 三天行程页签切换，日期、介绍、活动和路线同步更新。
2. 地图地点与时间轴活动双向高亮；地图只表达地点顺序，不提供导航。
3. 点击活动标题，在弹窗内修改活动名、时间和笔记；可取消、Esc 关闭，焦点限制在弹窗内并在关闭后返回。
4. 右侧以单行输入提交要求，支持示例调整与处理动效；结果和对话按计划归档，未支持的指令保留在清单中。
5. 快捷调整建议、精简的出行信息弹窗，以及自动记录和最终方案选择反馈。
6. 每个旅行计划保存独立行程、对话与结果版本，刷新可读取；保存失败时保留页面中的修改。手动编辑与有效助手调整自动留存快照，不再手动保存版本；可从任一版本选定最终方案。
7. 离开未选定的版本时提醒选择最终方案；允许直接返回并保留历史，已选定版本不重复提醒。导航不再显示「自动记录」。出行信息使用大字号日期与并列费用区，详见 [03-return-and-trip-info.md](../04-features/03-return-and-trip-info.md)。

## 当前能力边界

这是可运行的前端原型，尚未接入模型。初始数据为开发样本，三个示例由明确的本地规则执行，并提供处理与逐字显示动效；不支持的要求不会自动改写行程。

成功的本地示例调整创建结果快照，未知要求标记为「待处理」。多计划与侧栏的最新交互见 [01-plan-projects.md](../04-features/01-plan-projects.md)。后续接入约定见 [01-data-contract.md](../03-data/01-data-contract.md)。

园林图是新生成的独立素材，非原始设计图裁切，也不声明为具体园林实拍。地图由 SVG 独立绘制，既不是整张设计图背景，也不是高德真实地图。素材说明见 [02-assets-and-icons.md](02-assets-and-icons.md)。

## 动效与可访问性

- 初次进入：助手标题短距离淡入；固定导航和底部编辑区不参与位移，避免影响固定位置。
- 日期切换：同一块选中底板滑动；地点选中时同步显现标记光圈。
- 操作反馈：按钮按下微移、保存/更新出现提示，弹窗从触发动作后短距离进入。
- 尊重 `prefers-reduced-motion`，减少动态效果时内容直接显示。
- 表单有标签；地图支持 Tab、Enter、Space；对话区支持长文本换行；窄屏主要操作均可访问。

## 固定导航与底栏

页面外壳占满动态视口高度。顶部导航、窄屏切换栏、左侧底部信息栏及右侧编辑区保持可见，仅行程正文和消息记录独立滚动。导航采用半透明纸白背景、20px 背景模糊与饱和度修饰，底部信息栏使用较轻的模糊。低高度下收紧输入框高度与间距，并保留设备安全区。
