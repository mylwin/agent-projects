# 返回提醒与出行信息重排

日期：2026-11-03。本轮根据最新两张批注图继续细化，沿用暖白、酒红与衬线标题，不增加功能入口。

## 返回时再做选择

移除导航的「自动记录」和行程标题旁重复提示，保留自动持久化行为。底栏仍可随时选择最终方案；当用户从尚未选定的版本返回时，再询问是否把正在查看的版本设为最终方案。

- 「选定并返回」：更新最终版本标记，写入成功后完成原本的跳转，不复制版本。
- 「稍后选择，返回」：保留历史行程与已提交对话，暂不选择最终方案；已有选择时显示「保留原方案，返回」。
- 关闭按钮、Escape 或遮罩：取消跳转，继续查看当前计划，当前输入保留。
- 已经在查看选定版本时直接返回；同一计划内切换版本不出现离开提醒。
- 保存失败：提醒中显示错误，保留当前选择并提供再次提交的机会；不会误报成功并跳转。
- 助手调整中：选定按钮暂不可用；直接返回会暂停调整，再进入项目可继续处理。

路由使用 React Router 数据路由与 `useBlocker`，覆盖应用内返回入口、品牌入口、跨计划跳转及浏览器前进/后退。整页刷新、关闭标签页和跨域跳转不显示自定义对话框，之前已写入的本地记录仍保留。未发送的输入仅在当前计划页面内保留，本轮不增加跨页面输入草稿存储。

## 信息弹窗层级

参考 [Carbon 对话框规范](https://www.carbondesignsystem.com/building-blocks/core/components/modal/guidelines) 中的信息展示、明确动作与响应式尺寸建议：出行信息保持只读查看，返回提醒承担选择动作。具体字号、颜色与结构按现有旅行日笺风格设计。

1. 标题和计划名用于识别所属项目；去掉英文装饰标题。
2. 目的地用 34px，同行人数与天数用 15–16px；目的地与日期之间用一条轻分隔线。
3. 旅行日期用桌面 25px、手机 22px，年份单列为次要信息。
4. 全团预算与活动费用放在同一区域并列显示，金额桌面 30px、手机 26px；费用范围紧随各自金额，避免与下方提醒混排。
5. 出发确认事项改为两条短句，正文 14px，重点核对预约、门票和交通。

手机弹窗宽度明确限制在视口内；低高度和 200% 等效布局下允许纵向滚动。焦点限制在弹窗可用控件中，关闭后返回触发位置。沿用短距离进入、按钮按压和选定状态反馈，尊重减少动态效果设置。

本轮未接入真实模型、服务端保存或跨设备同步；仍使用现有浏览器项目存储。
